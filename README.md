# 🌍 Air Quality Monitoring – Mini Project

## 📌 Project Overview

This project focuses on **cleaning, transforming, and analyzing air quality data using Excel and Power BI**.

The cleaned data is used to create interactive reports and an **Air Quality Monitoring Dashboard** to understand pollutant levels, Air Quality Index (AQI), environmental conditions, and air pollution trends.

The main objective of this project is to demonstrate data cleaning and transformation techniques in Excel and develop interactive Power BI visualizations for better understanding of air quality patterns and pollution trends.

---

## 🎯 Objectives

* Analyze air quality levels across different cities and regions.
* Identify variations in major air pollutants.
* Analyze AQI values and AQI categories across different locations and dates.
* Identify air pollution trends over time.
* Understand air quality along with temperature, humidity, and wind speed.
* Create an interactive Power BI dashboard for air quality analysis.

---

---

## 📊 Dataset Attributes

| Attribute          | Data Type    | Description                                  |
| ------------------ | ------------ | -------------------------------------------- |
| Record_ID          | Text         | Unique identification number for each record |
| Date               | Date         | Date of air quality observation              |
| City               | Text         | Name of the city                             |
| Region             | Text         | Geographic region                            |
| Monitoring_Station | Text         | Name of the monitoring station               |
| PM2.5_ug_m3        | Decimal      | Concentration of fine particulate matter     |
| PM10_ug_m3         | Decimal      | Concentration of particulate matter          |
| NO2_ug_m3          | Decimal      | Nitrogen dioxide concentration               |
| SO2_ug_m3          | Decimal      | Sulfur dioxide concentration                 |
| CO_mg_m3           | Decimal      | Carbon monoxide concentration                |
| O3_ug_m3           | Decimal      | Ozone concentration                          |
| Temperature_C      | Decimal      | Temperature in Celsius                       |
| Humidity_Percent   | Decimal      | Humidity percentage                          |
| Wind_Speed_m_s     | Decimal      | Wind speed in metres per second              |
| AQI                | Whole Number | Air Quality Index value                      |
| AQI_Category       | Text         | Category/classification of air quality       |
